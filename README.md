# Фитнесс зөвлөгөө, тэмдэглэл

Утсан дээр суудаг, бүртгэлтэй, офлайн ажилладаг фитнесс апп.
Хэмжилтээс илчлэг/макро тооцоолол, дасгалын хөтөлбөр, монгол хоолны сан,
дасгал/хоол/жин/зургийн бүртгэл.

**Технологи:** цэвэр HTML + CSS + JavaScript (framework-гүй) · Supabase (данс, өгөгдөл, зураг) · PWA
**Байршуулалт:** GitHub Pages (үнэгүй)

---

## 0. Юу хэрэгтэй вэ

| Хэрэгсэл | Зориулалт | Төлбөр |
|---|---|---|
| VS Code | код засах | үнэгүй |
| Python | локал сервер (`python -m http.server`) | үнэгүй |
| Git | GitHub руу түлхэх | үнэгүй |
| GitHub данс | байршуулалт | үнэгүй |
| Supabase данс | нэвтрэлт, өгөгдөл, зураг | үнэгүй багц хангалттай |

> **Python яагаад хэрэгтэй вэ?** Аппын кодонд Python **огт** ороогүй.
> Гэхдээ PWA-гийн service worker болон Supabase нэвтрэлт `file://` дээр ажиллахгүй.
> Тиймээс туршихдаа заавал `http://localhost` шаардлагатай.

---

## 1. Локал дээр ажиллуулж үзэх (5 минут)

```bash
cd huch-app
python -m http.server 5500
```

Хөтөч дээрээ **http://localhost:5500** гэж нээнэ.

Supabase холбогдсон тул **нэвтрэх дэлгэц** гарч ирнэ. Имэйлээрээ бүртгүүлээд
профайлаа бөглөж үзээрэй. Хэрэв «Бүртгэлгүйгээр ашиглах» дарвал өгөгдөл
зөвхөн тухайн хөтөч дээр үлдэнэ (дараа нь бүртгүүлэхэд автоматаар дансанд шилжинэ).

---

## 2. Supabase — ✅ ХИЙГДСЭН

Энэ хэсэг аль хэдийн тохируулагдсан. Дахин хийх шаардлагагүй.

| Зүйл | Утга |
|---|---|
| Байгууллага | Fitness app |
| Төсөл | `zparrhkvgdzchhxqzezu` |
| Хаяг | `https://zparrhkvgdzchhxqzezu.supabase.co` |
| Бүс | ap-southeast-2 (Сидней) |
| Хүснэгт | `profiles` `measurements` `workout_sets` `food_entries` `photos` |
| Storage | `progress` (хаалттай) |
| RLS | ✅ бүх хүснэгт дээр асаалттай |
| Аюулгүй байдлын шалгалт | ✅ анхааруулга байхгүй |

Түлхүүр нь `js/config.js`-д бичигдсэн. `supabase-schema.sql` нь зөвхөн
**нөөц/лавлагаа** болгож үлдсэн — шинэ төсөл дээр дахин ажиллуулах бол хэрэг болно.

### 2.1 Үлдсэн ГАРААР хийх 2 тохиргоо

Эдгээрийг Supabase дашбоард дээрээс өөрөө хийнэ (API-аар өөрчлөх боломжгүй):

**a) Имэйл баталгаажуулалт унтраах** (найз нөхөддөө хурдан өгөх бол)
`Authentication → Sign In / Providers → Email → Confirm email → унтраах`
Асаалттай бол хүн бүр имэйл дэх холбоосыг дарж байж нэвтэрнэ.

**b) Хаягаа бүртгүүлэх** — GitHub Pages хаягаа авсны дараа
`Authentication → URL Configuration`
- **Site URL**: `https://ТАНЫ-НЭР.github.io/huch/`
- **Redirect URLs**-д мөн нэм

Энэ алхмыг алгасвал нууц үг сэргээх имэйл буруу хаяг руу чиглэнэ.
(Нэвтрэх/бүртгүүлэхэд нөлөөлөхгүй — зөвхөн имэйлээр илгээх холбоосуудад.)

## 3. GitHub Pages дээр байршуулах (10 минут)

### 3.1 Repo үүсгэх
1. https://github.com/new
2. Repository name: `huch`
3. **Public** сонгоно (Pages үнэгүй байхын тулд)
4. **Create repository**

### 3.2 Кодоо түлхэх
VS Code-ийн терминал дээр, `huch-app` фолдер дотор:

```bash
git init
git add .
git commit -m "ХҮЧ — анхны хувилбар"
git branch -M main
git remote add origin https://github.com/ТАНЫ-НЭР/huch.git
git push -u origin main
```

### 3.3 Pages асаах
1. Repo → **Settings** → зүүн талд **Pages**
2. **Source**: `Deploy from a branch`
3. **Branch**: `main` · фолдер `/ (root)` → **Save**
4. 1–2 минутын дараа хаяг гарна:

```
https://ТАНЫ-НЭР.github.io/huch/
```

### 3.4 Supabase-д хаягаа зөвшөөрөх
Supabase → **Authentication → URL Configuration**:
- **Site URL**: `https://ТАНЫ-НЭР.github.io/huch/`
- **Redirect URLs**-д мөн адил хаягаа нэм

Энэ алхмыг алгасвал нууц үг сэргээх имэйл буруу хаяг руу чиглэнэ.

## 4. Утсандаа суулгах

**Android (Chrome):** хаягийг нээгээд → цэс (⋮) → **«Add to Home screen»**
Эсвэл апп дотроос **Профайл → Утсандаа суулгах** товч гарч ирнэ.

**iPhone (Safari):** хаягийг нээгээд → доод талын **Хуваалцах** (↑) → **«Add to Home Screen»**
> iPhone дээр заавал **Safari** ашиглана. Chrome дээр суулгах товч гарахгүй.

Суулгасны дараа дэлгэц дээр «Зөвлөгөө» дүрс гарч, жинхэнэ апп шиг бүтэн дэлгэцээр нээгдэнэ.
Сүлжээгүй үед ч ажиллаж, онлайн болоход автоматаар синк хийнэ.

---

## 5. Найз нөхдөө нэмэх

Хаягаа өгөхөд л болно — хүн бүр өөрөө бүртгүүлнэ.
Хүн бүрийн өгөгдөл RLS-ээр тусгаарлагдсан тул бие биенийхээ мэдээллийг **харах боломжгүй**.

**Хаалттай бүлэг болгох:** Supabase → Authentication → Providers → Email →
**«Allow new users to sign up»** унтраа. Дараа нь хэрэглэгчдийг гараар
**Authentication → Users → Add user** дээрээс нэмнэ.

Үнэгүй багцын хязгаар (10–50 хүнд илүү хангалттай):
өгөгдлийн бааз 500 MB · файл 1 GB · сарын идэвхтэй хэрэглэгч 50,000

## 7. Засвар оруулах үед

### Хоол нэмэх
`js/data.js` дотор `FOODS` массивт мөр нэмнэ:

```js
{n:"Шинэ бүтээгдэхүүн", cat:"Дэлгүүр", u:"100г", k:250, p:12, f:15, c:18, r:"pro", nb:"тэмдэглэл"},
```

- `u` — `"100г"` (100 грамм тутамд) эсвэл `"1ш (50г)"` (нэг ширхэг)
- `k,p,f,c` — тухайн нэгжид ногдох ккал / уураг / өөх / нүүрс ус
- `r` — `pro` `carb` `fat` `veg` `mix` (цэс үүсгэгч ашиглана)

### Дасгал нэмэх
`js/data.js` → `EX` объектод түлхүүр нэмээд, `SPLITS` дотор ашиглана.

### ⚠️ Кодоо шинэчилсэн бол заавал
`sw.js`-ийн эхний мөрийг **өөрчил**:

```js
const CACHE = 'huch-v3';   // v2 → v3 болгов
```

Эс тэгвээс хэрэглэгчид хуучин хувилбарыг үзсээр байна (service worker кэшлэсэн байна).

Дараа нь:
```bash
git add .
git commit -m "хоол нэмэв"
git push
```
1–2 минутын дараа GitHub Pages шинэчлэгдэнэ.

## 8. Асуудал гарвал

| Шинж тэмдэг | Шалтгаан / шийдэл |
|---|---|
| «Оффлайн горим» гэж байнга харагдана | `js/config.js` хоосон эсвэл түлхүүр буруу |
| Нэвтэрч чадахгүй, `Failed to fetch` | Supabase URL буруу, эсвэл интернэт тасарсан |
| Бүртгүүлээд нэвтэрч чадахгүй | Имэйл баталгаажуулалт асаалттай — имэйлээ шалга, эсвэл 2.5-ыг үз |
| Өгөгдөл синк болохгүй | `supabase-schema.sql` ажиллуулаагүй. SQL Editor дээр дахин RUN дар |
| Бусдын өгөгдөл харагдаж байна | RLS асаагүй. `supabase-schema.sql`-ийн 3-р хэсгийг заавал ажиллуул |
| Зураг ачаалагдахгүй | `progress` bucket үүсээгүй, эсвэл storage policy дутуу |
| Утсанд суулгах товч гарахгүй | iPhone дээр Safari ашигла. Android дээр HTTPS хаягаар нээ |
| Шинэчилсэн код харагдахгүй | `sw.js` доторх `CACHE` дугаарыг нэмэгдүүл, дараа нь хуудсаа хүчээр сэргээ |
| GitHub Pages 404 өгч байна | Repo **Public** эсэх, `.nojekyll` файл байгаа эсэхийг шалга |

**Хөтчийн алдааг харах:** F12 → Console таб. Улаан мөрүүд нь алдаа.

---

## 9. Өгөгдлөө нөөцлөх

Апп доторх **Профайл → Нөөц татах (JSON)** нь бүх өгөгдлийг файл болгож татна.
**Нөөцөөс сэргээх** нь буцааж ачаална. Supabase унтарсан ч энэ файлаар өгөгдлөө аварна.

## 10. Анхааруулга

Энэ апп бол мэдээллийн зориулалттай хэрэгсэл. Илчлэгийн утга нь ердийн жор,
савлагааны шошгоны дундаж дээр тулгуурласан **ойролцоо** тоо (±10–15%).
Эрүүл мэндийн асуудалтай, эм уудаг, жирэмсэн бол эмчтэйгээ заавал зөвлөнө үү.
